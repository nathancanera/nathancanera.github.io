Run the main file to output colored versions of all images. 

main.py works by invoking a function (jpg) on all the small jpg functions which uses the brute force, naive alignment logic
and calls a function (tif) on all the tif file with the image pyramid logic. 

naive.py contains the code for the jpg processing logic and full.py contains the tif processing logic
logic.py contains helper functions that both of the above use like crop, align, pyramid_align, etc
