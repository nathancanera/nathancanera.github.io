Part 1: Fun with filters

Part 1.1: Convolutions from Scratch!

In part 1 of the project I implemented convolution two ways. The first was with 4 for loops and the second was with 2 for loops and numpy's vectorized functions. Very quickly I noticed that the 2 for loop implementation was significantly faster than the 4 for loop implementation. Numpy's vectorized functions are faster than the 2 extra for loops so this made sense. When comparing to scipy.signal.convolve2d though, The difference was extremeley obvious. Scipy's implementation was orders of magnitude faster than both of my implementations. This is likely due to the fact that scipy's implementation is written in C and optimized for performance. One thing to note, is that my implementations pad with zeros while scipy's implementation pads with edge values. This can lead to different results when convolving with certain kernels but it shows in my examples with dark borders around the image.





Part 1.2: Finite Difference Operator

Part 1.2 tasked us with finding the partial derivatives of an image in the x and y directions using the finite difference operator. Then I used the np.hypot function to find the magnitude of the gradient at each pixel. The results were as expected, with the x derivative highlighting vertical edges and the y derivative highlighting horizontal edges. The magnitude image highlighted all edges in the image. With the gradient magnitude image, I applied a threshold to create a binary edge map. My threshold was 0.06 * the maximum value in the gradient magnitude image which came out to about 0.085. When deciding my threshold, I wanted to minimize noise but include as many details as I could, specifically the buildings in the background, so I chose a smaller threshold. The noise was minimal, however the grass in the photo was quite overpowering.





Part 1.3: Derivative of Gaussian (DoG) Filter

In part 1.3, we were tasked with repeating part 1.2, but with a blur applied to the image with the goal of reducing noise. I attempted this in two ways, first by blurring the image and then convolving and second by convolving with the derivative of Gaussian filters to achieve the same effect of the blur but in one convolution step.

One thing to note is that the two different methods used achieve the same result. This is because the derivative of Gaussian filters are equivalent to first blurring the image and then applying the finite difference operator.





Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening

In part 2.1, I implemented image sharpening using the unsharp masking technique. This involved blurring the image with a Gaussian filter and then subtracting the blurred image from the original image to create a mask. This mask was then added back to the original image to enhance edges and details. I experimented with different values of alpha, which controls the amount of sharpening applied. A higher alpha value results in more pronounced sharpening, while a lower value produces a subtler effect. I found that an alpha value of 1.5 provided a good balance between enhancing details and avoiding excessive noise amplification. We were also tasked with first blurring an image and then trying to sharpen it again.

Part 2.2: Hybrid Imagesg

In part 2.2, I created hybrid images by combining the low-frequency components of one image with the high-frequency components of another image. This was achieved by applying a Gaussian blur to one image to extract its low frequencies and using a high-pass filter on the other image to isolate its high frequencies. The two resulting images were then added together to create the hybrid image. I experimented with different cutoff frequencies for the Gaussian blur and high-pass filter to see how they affected the appearance of the hybrid image. A lower cutoff frequency for the Gaussian blur resulted in a more pronounced low-frequency component, while a higher cutoff frequency for the high-pass filter emphasized more details from the second image. The choice of images also played a significant role in the effectiveness of the hybrid image. I found that using images with distinct features and contrasting frequency content produced more visually interesting results.

Part 2.3 & 2.4: Gaussian and Laplacian Stacks For Multiresolution Blending

in part 2.3 and 2.4 I created functions to generate Gaussian and Laplacian stacks of images. These stacks were then used to perform multiresolution blending of two images. The blending process involved creating a mask to define the regions of each image to be blended, constructing Gaussian stacks for the mask, and then using these stacks to blend the corresponding levels of the Laplacian stacks of the two images. The results of the blending were visually appealing, with smooth transitions between the two images. At first the seams were very obvious, but after adjusting how I create the mask by using np.linspace instead of np.ones and np.zeros, the seams were much less noticeable. The choice of images also played a significant role in the effectiveness of the blending. I found that using images with similar color tones and lighting conditions produced more seamless results.
